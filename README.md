# Gênio IA - Deploy rápido (Vercel recomendado)

1. Crie repositório no GitHub e cole estes arquivos.
2. No Vercel, importe o repositório.
3. Configure Environment Variables no Vercel:
   - OPENAI_API_KEY = coloca_tua_chave_aqui
   - NEXT_PUBLIC_BASE_URL = https://seu-site.vercel.app
   - STRIPE_SECRET_KEY = sk_...
   - STRIPE_PRICE_ID = price_...
4. Clique em Deploy.

Teste local:
- npm install
- npm run dev
